# GiftLab Online V1 — UpgradeLab-style rebuild

Эта версия построена прямо на кодовой базе загруженного UpgradeLab V82, а не на предыдущем упрощённом GiftLab.

Что сохранено из UpgradeLab:
- регистрация/вход Firebase;
- основной upgrade wheel и быстрые шансы;
- inventory source selection;
- кейсы 1–10 за раз с рулеткой;
- контракты;
- история;
- Crystal Shop;
- Gift Pass (бывший Upgrade Pass);
- профили, ежедневная награда, достижения;
- промокоды и админ-выдачи;
- отдельный Normal/Sandbox;
- темы, настройки и live feed.

Что заменено:
- CS2 каталог убран;
- встроено 118 Telegram Gift коллекций;
- создано 24 Gift-кейса;
- вся игровая валюта в интерфейсе — виртуальные Stars ★;
- Normal стартует с 5 000 ★;
- Sandbox имеет отдельное состояние и infiniteMoney;
- case drops настроены более щедро для виртуального режима;
- брендинг заменён на GiftLab.

## Админка
Админ-панель НЕ является отдельной публичной страницей. Она находится в профиле и остаётся `hidden`, пока `profiles/{uid}.role` не равен `admin`.

Чтобы назначить админа:
1. Firebase -> Firestore -> profiles -> документ твоего UID.
2. Добавь string поле `role` со значением `admin`.
3. Опубликуй `firestore.rules` из этого архива.

Обычный пользователь не может сам изменить поле role по Rules.

## Важно о каталоге
Названия коллекций — реальные названия Telegram Gifts. Цены со знаком ★ в этой сборке — ВИРТУАЛЬНАЯ игровая экономика симулятора, а не заявленные рыночные цены Telegram/Fragment.

Часть flagship-обложек использует локальные публичные изображения, остальные коллекции имеют локальные стилизованные covers, чтобы сайт не зависел от сторонних CDN и не оставался с 4 предметами. Следующий шаг — подключение официальных анимированных gift assets / TGS-WebM источника.
