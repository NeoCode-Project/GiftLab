# GiftLab V5

Что изменено:

- Нормальный Upgrade Spinner: круглая рулетка с зелёной зоной шанса и настоящим вращением.
- Sandbox и обычный режим полностью разделены: отдельный баланс, инвентарь, XP, Prime, награды и статистика.
- Sandbox всегда показывает ∞ Stars.
- Все NFT, которые есть в кейсах, одновременно доступны в Market и Upgrade.
- Кейсы имеют повышенный виртуальный RTP ~116–123%.
- Продажа предметов теперь возвращает 78% Virtual Value.
- Battles переработаны: выбор кейса, 1/3/5 раундов, Classic и Crazy, счёт и история каждого раунда.
- Админка промокодов через Firebase.
- Firebase остаётся необязательным: если он сломается, основная игра продолжит работать Local.

## Как сделать себя админом

1. Задеплой V5.
2. Открой страницу `Админ`.
3. Скопируй Firebase UID.
4. Firebase Console -> Firestore -> Data.
5. Создай collection `admins`.
6. Document ID = твой UID.
7. Добавь boolean поле:
   `enabled = true`
8. Firestore -> Rules -> вставь `firestore.rules` из архива -> Publish.
9. Обнови сайт.

После этого кнопка `Создать промокод` станет активной.

## Промокоды

Админ может создавать:
- Stars
- XP
- бесплатные кейсы

Промокоды лежат:
`promos/{CODE}`

Игрок может активировать каждый код только один раз в своём профиле.

## Важное ограничение

Это виртуальный симулятор, поэтому клиентскую экономику нельзя считать защищённой от читов. Если потом нужен публичный проект с жёсткой защитой, выдачу кейсов, апгрейды, таймеры и redeem промокодов надо перенести на сервер/Cloud Functions.
